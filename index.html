Skill cho Muse · Web game 3D nhiều người chơi

GAME3D

Dựng web game 3D (Three.js + Socket.IO) với hệ phong cách ĐÁNH SỐ — gọi phong cách bằng mã: nhân vật NV-01…NV-10, ngoại cảnh NC-01…NC-07, biến thể TG / TT / M và combo sẵn CB-01…CB-05.

⬇ Tải gói skill (.zip) Xem mã nguồn trên GitHub

🎭 Nhân vật — mã NV

10 phong cách nhân vật 3D dựng bằng code (hình khối + texture thủ tục), không cần model ngoài.

NV-01

Mô phỏng 3D chân thật

Tỉ lệ người thật, da/vải tự nhiên — chuẩn mô phỏng.

NV-02

Hoạt hình 3D kiểu Pixar

Đầu hơi to, mặt biểu cảm, màu tươi bóng.

NV-03

Chibi 3D

Đầu to, mắt long lanh, má hồng — dễ thương cho trẻ.

NV-04

Anime 3D (cel-shading)

Viền nét đen, tô màu phẳng 2–3 tông.

NV-05

Bán chân thật

Gần tỉ lệ thật, da mịn lý tưởng hoá, mắt hơi to.

NV-06

Low-poly tối giản

Khối ít mặt, màu phẳng — nhẹ nhất, tải nhanh.

NV-07

Voxel / khối hộp

Toàn thân ghép từ khối vuông kiểu Minecraft.

NV-08

Đất sét (clay)

Bề mặt như nặn tay, màu đất ấm — cổ tích.

NV-09

Tiên hiệp 3D

Cổ trang, tóc dài, linh khí hào quang.

NV-10

Mô hình thu nhỏ

Như tượng nhựa nhỏ có đế — cho sa bàn.

🏞️ Ngoại cảnh — mã NC

7 phong cách bối cảnh, phối đẹp nhất với mã nhân vật gợi ý trong skill.

NC-01

Chân thật tự nhiên

Vân gỗ/vỏ cây/cỏ/ngói, nắng thật, nước sông động.

NC-02

Pastel mềm

Tán cây tròn mềm, màu sáng dịu, mây trắng tròn.

NC-03

Sa bàn thu nhỏ

Cả cảnh như mô hình diorama trên bàn.

NC-04

Voxel

Đồi/nhà/cây đều khối hộp theo lưới.

NC-05

Low-poly phẳng

Hình học ít mặt, trời gradient, không texture.

NC-06

Cel-shaded

Mây vẽ, màu tươi, viền nét ở vật chính.

NC-07

Đất sét

Nhà/cây như nặn tay, màu đất ấm.

Ghép thêm mã biến thể sau mã chính, ví dụ: NV-01 + NC-01 + TG-4 + M-5 = làng chân thật, đêm trăng, ngày Tết.

⚙️ Kiến trúc kèm theo trong skill

Server Node.js + Socket.IO Client 1 file HTML Three.js vendor local — không phụ thuộc CDN Texture thủ tục vẽ bằng canvas Âm thanh WebAudio tổng hợp Joystick điện thoại không ngược hướng HUD không chồng lấn màn hình dọc Deploy GitHub + Render miễn phí

📥 Cài đặt skill

  1. Tải gói skill-game3d.zip ở đầu trang và giải nén.
  2. Chép thư mục game3d vào ~/workspace/custom-skills/ của Muse.
  3. Gọi bằng mã số, ví dụ: “tạo game 3D phong cách NV-05 + NC-06” hoặc “đổi game sang CB-02, thêm TG-4”.
